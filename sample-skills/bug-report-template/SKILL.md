# Bug Report Template

Turn a developer's rough description of a problem into a clear, structured
bug report.

1. Identify what was expected vs. what actually happened.
2. Extract concrete steps to reproduce, in order.
3. Note the environment (OS, version, browser) if mentioned.
4. Fill in `templates/bug-report.md` and return the result.
