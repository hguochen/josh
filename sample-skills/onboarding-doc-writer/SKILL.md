# Onboarding Doc Writer

Turn tribal knowledge about a system or team process into a written
onboarding section a new hire can follow without asking around.

1. Identify the audience (new engineer, new team member, new service owner).
2. List the prerequisites and access they'll need first.
3. Write step-by-step setup instructions, in the order they're actually needed.
4. Fill in `templates/onboarding-section.md` and return the result.
